# -chip8emu0.1.11.x8.17.26

Python CHIP-8 emulator. Built-in ROMs are listed in **Built-in ROMs**.

## Built-in ROM catalog

| ROM | Shortcut | Controls |
| --- | --- | --- |
| Pong | F2 | Q/A left paddle, E/D right paddle |
| Tetris | F3 | Q/E move, S fast drop |

Run:

```
python3 chip8emu0.1.1x.py
```

or:

```
python3 acchip8emu1.x.py
```
